# MIT 6.566 - Paper Reading Summary 







This course is much more recent than 6.858 and thus includes more modern topics such as security practices in AI engineering. In this [lecture](https://mit.hosted.panopto.com/Panopto/Pages/Viewer.aspx?id=1ef8e5b1-a076-4300-b9fb-b3df013fe10a), [Anish](https://anish.io/), an MIT alumini, now researcher @Cursor, gave a lecture on the findings from [Camel](https://css.csail.mit.edu/6.566/2026/readings/camel.pdf), a way to defend against prompt injection attacks against LLMs. He laid out the terminologies quite clearly in the lecture: `data flow`, `control flow`, `program flow`, etc.
